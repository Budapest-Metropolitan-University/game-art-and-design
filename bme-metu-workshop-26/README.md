# BME METU workshop 2026

Szabadon használható asset-források a workshophoz (2D / 2.5D / 3D).

| Forrás | Licenc | Megjegyzés |
|---|---|---|
| [Kenney](https://kenney.nl) | CC0 | 2D sprite-ok, 3D modellek, UI, hangok egy stílusban; glTF is |
| [KayKit](https://kaylousberg.com) | CC0 | Low-poly karakterek és környezetek glTF-ben, külön animációs csomag |
| [Quaternius](https://quaternius.com) | Szabad, forrásmegjelölés nélkül | 50+ rigelt, animált karakter; FBX/Blend → GLB-be konvertálni |
| [Poly Pizza](https://poly.pizza) | CC0 vagy CC BY | 10 600+ low-poly modell; CC BY esetén a szerzőt fel kell tüntetni |
| [Mixamo](https://www.mixamo.com) | Adobe feltételek | Adobe-fiók kell, FBX; nyers fájlt nyilvános repóba ne tegyünk |

**Egy forrás, egy stílus.** CC0 = közkincs: szabadon használható, módosítható és publikálható.

A dia megnyitása: `index.html` (GitHub Pages-en a repó főoldala).
